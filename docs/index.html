端末を設定する（macOS / Linux）

トークンは管理者から受け取ってください（このページにはありません）。

curl -fsSkO https://<このサーバー>/client/caddy-root.crt
curl -fsSO --cacert caddy-root.crt https://<このサーバー>/client/setup-client.sh
chmod +x setup-client.sh
OTEL_INGEST_TOKEN=<トークン> ./setup-client.sh \
  --endpoint https://<このサーバー> --ca-cert ./caddy-root.crt

最初の証明書だけは検証なし（-k）で取ることになります。気になる場合は openssl x509 -in caddy-root.crt -noout -fingerprint -sha256 の値を管理者に確かめてください。
